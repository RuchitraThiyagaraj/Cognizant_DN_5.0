# Selenium Test Automation – Python Full Stack Engineer

## Overview

As part of the **Cognizant Digital Nurture 5.0 – Python Full Stack Engineer Deep Skilling Program**, this module focuses on **Software Testing, Quality Assurance, and Selenium Test Automation**.

This module provides practical experience in understanding QA concepts, automating web applications using **Selenium WebDriver**, creating automated test scripts, implementing waits, performing browser interactions, and developing maintainable automation frameworks using **PyTest and Page Object Model (POM)**.

---

## Learning Objectives

The objectives of this module are:

* Understand software testing fundamentals.
* Learn Quality Assurance concepts and testing processes.
* Understand SDLC, STLC, TDLC, and Agile testing.
* Learn Selenium WebDriver architecture.
* Automate browser activities using Selenium.
* Work with Selenium locators.
* Handle dynamic web elements using waits.
* Create automated test cases using PyTest.
* Generate test reports.
* Implement Page Object Model (POM).
