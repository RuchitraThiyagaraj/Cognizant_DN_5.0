# Frontend Development – Python Full Stack Engineer

## Overview

As part of the **Cognizant Digital Nurture 5.0 – Python Full Stack Engineer Deep Skilling Program**, this module focuses on modern frontend application development.

A complete **Student Portal application** is developed progressively through ten hands-on exercises using **HTML5, CSS3, JavaScript, React, Angular, and Vue.js**.

The module covers frontend fundamentals, responsive design, JavaScript programming, asynchronous operations, Single Page Applications (SPA), routing, state management, accessibility, and API integration.
