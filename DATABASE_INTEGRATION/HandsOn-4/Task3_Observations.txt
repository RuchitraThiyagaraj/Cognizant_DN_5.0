Observation

Version 1:
• One query fetches all enrollments.
• One additional query runs for each enrollment.
• Total Queries = N + 1

Example:
10 enrollments
1 + 10 = 11 queries

Version 2:
• Uses a JOIN.
• Fetches all data in one SQL query.
• Total Queries = 1

Conclusion:
JOIN is faster because it reduces database queries, improves performance, and avoids the N+1 Query Problem.
